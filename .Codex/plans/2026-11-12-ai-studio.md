# 留白 AI Studio（取代资讯/文章型首页）

日期：2026-11-12

## 方向
网站从内容展示转为 AI 工具：AI 对话、AI 工具箱、提示词库、会话历史、模型设置。资讯/书房/日常等旧文件保留可访问，但不再进入主导航。

## 模型接入（已实测）
- 默认 Pollinations OpenAI 兼容公共端点：免 Key、支持 CORS、SSE 流式、中文回复；仅使用 choices.delta.content，忽略 reasoning。
- 可选智谱 GLM / DeepSeek / OpenAI / 自定义 OpenAI 兼容端点，Key 仅 localStorage，静态站无服务器。
- 公共模式明确提示限流与隐私边界，不伪造 AI 回复。

## 页面
1. index.html：多轮流式对话、停止/重试/复制、会话管理、快捷任务、语音输入与朗读（浏览器支持时）。
2. tools.html：摘要、翻译、润色、代码解释、头脑风暴、计划、表格提取等模板，流式输出并转对话。
3. prompts.html：内置提示词搜索/复制/使用 + 自定义提示词。
4. history.html：搜索/继续/删除/导出 JSON 与 Markdown。
5. settings.html：服务商/端点/模型/Key/温度/系统提示词、连接测试、全站数据导入导出。

## 架构
assets/ai-core.js（配置、流式请求、会话存储、Markdown 安全渲染、导出）；assets/shell.js（统一导航与模型状态）；assets/ai.css；各 page-*.js。全部原生 JS、无构建依赖、GitHub Pages 可运行。

## 验证
公共模型真实流式对话、停止、历史恢复、工具模板、提示词跳转、设置持久化、导出导入、移动端；无 Key 的私有服务商显示明确配置错误而非假回复。
